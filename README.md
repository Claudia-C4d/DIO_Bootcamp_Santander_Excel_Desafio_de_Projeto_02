# DIO_Bootcamp_Santander_Excel_Desafio_de_Projeto_02
Desafio de Projeto DIO Bootcamp Santander - Excel com IA- Criando um Organizador de Imposto de Renda

Esse material é referente ao Desafio de Projeto “Criando um Organizador de Imposto de Renda com Excel” para o curso DIO. Bootcamp Santander Excel com IA, e consiste nos seguintes arquivos:

- DIO_Bootcamp_Santander_Excel_IA_Desafio_de_Projeto_02 (arquivo Excel em .xlsx)
- DIO_Bootcamp_Santander_Excel_IA_Desafio_de_Projeto_02.pdf (dashboards em .pdf)
  
O desafio consiste em criar uma ferramenta interativa para a organização de dados referentes ao Imposto de Renda, como dados do titular, informes de rendimentos e notas bancárias. Foram utilizados, basicamente, campos para preenchimento com formatação de dados, listas suspensas, e links de conexão entre as páginas.

Foi um desafio muito prático com o intuito de criar um visual de aplicação, de fácil interação.
